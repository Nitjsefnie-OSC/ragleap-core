# ragleap-physical (planned)

**Status: planned, no code yet.** Nothing here is released or tested.

The goal: a bridge from RagLeap to open-source simulators and robot software (for example MuJoCo and ROS 2), so contributors can build and test physical-system features safely. Simulation first, observe-only first. Nothing here controls real hardware.

- Plan, decisions, safety rules and conventions: [docs/HANDOVER.md](docs/HANDOVER.md)

Life-safety systems, medical devices and vehicles on public roads are out of scope and will never be supported.
